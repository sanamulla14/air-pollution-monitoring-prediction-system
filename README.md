# 🌫️ Air Pollution Monitoring and Prediction System

A Streamlit-based web application for monitoring, analyzing, and predicting Air Quality Index (AQI) across major Indian cities.

## 📌 Project Overview

This project provides an interactive Air Quality Dashboard that allows users to select Indian cities and view AQI information, pollution trends, health advisories, data visualizations, and AQI predictions.

The application uses Python, Streamlit, data analysis, visualization, and Machine Learning techniques.

## 🚀 Features

- 🌍 Air Quality Dashboard
- 🏙️ AQI monitoring for multiple Indian cities
- 📊 AQI trend visualization
- 🧪 Pollution correlation heatmap
- 📦 Pollution level distribution
- 🌡️ Temperature vs AQI analysis
- 🔮 Actual vs Predicted AQI visualization
- 🤖 AQI prediction using Linear Regression
- 📈 R² Score and RMSE model evaluation
- 🧑‍⚕️ Health advisory based on AQI level
- 🗺️ Interactive map of Indian cities
- 📥 Download AQI data as CSV
- 📅 Monthly/seasonal AQI analysis

## 🛠️ Technologies Used

## 🤖 Machine Learning

The project uses **Linear Regression** to predict AQI.

### Features used:

- PM2.5
- PM10
- NO2
- SO2
- CO2
- Temperature
- Humidity
- Wind Speed

### Model Evaluation

The model performance is evaluated using:

- R² Score
- RMSE (Root Mean Squared Error)
